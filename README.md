## Descripción del taller

Este proyecto contiene la solución en Java de los ejercicios del taller de recursividad.

El taller desarrolla diferentes problemas utilizando funciones recursivas, entre ellos:

- Factorial.
- Sumatoria.
- Sumatoria de fracciones.
- Inversión de un número.
- Suma de los dígitos.
- Potencia.
- Máximo común divisor mediante el algoritmo de Euclides.
- Cociente mediante restas sucesivas.
- Multiplicación mediante sumas sucesivas.
- Suma de los elementos de un vector.
- Suma de los elementos de una matriz.
- Serie de Fibonacci.
- Función de Ackermann.

Los programas están organizados dentro del paquete `Recursividad`.
